Why the parent scores 0.2778 (CLAIM) — short version

Byte-verified lineage: corroborated multi-layer ridge h19-5 (121,131 px, 0.1922) → dot-thinned at 2.8 px (44,090 dots, 0.2600) → pruned within 2 px of the catalogue (37,654 dots, 0.2778). The DTI metric charges 0.2 per unit mass but credits each truth pixel once (300 m triangular kernel, max), so dotted emission at kernel spacing beats continuous ridges ~3× on mass efficiency, masked-catalogue dots are pure cost, and a unit dot pays only if truth lies within ≈283 m.
